신규 매점 물품 등록

등록된 물품은 매점 태블릿 키오스크 쇼핑몰에 즉시 진열됩니다.

⚙️ 설정 ↗
권장 포맷: JPG, PNG, WebP, SVG (500KB 이하)

📁 상품 일괄 등록 (CSV)

CSV 양식에 상품 정보를 입력 후 업로드하세요. 입력 오류 발생 시 전량 자동 롤백됩니다.

📌 작성 안내:

  • 상품명, 카테고리, 가격, 재고는 필수입니다.
  • 상품코드를 비워둘 경우 P001부터 자동 채번됩니다.
  • 가격은 1 이상, 재고는 0 이상의 숫자여야 합니다.
  • 등록 후 개별 상품 사진을 바로 업로드하실 수 있습니다.

✏️ 상품 정보 및 분류 수정
